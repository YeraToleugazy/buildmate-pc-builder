# BuildMate: PC Builder Platform

A web application for building a PC from parts with automatic compatibility
checking, price calculation and saved builds. Final Exam Project for the
discipline "Development of Web Applications in Java Spring".

## Features
- Parts catalog with search and filters
- PC builder with slots (CPU, motherboard, RAM, GPU, power supply, case)
- Compatibility rules (socket, memory type, case size, GPU length, power)
- Automatic total price calculation
- Saved builds and team builds with roles
- Registration and login

## Tech Stack
Java 17, Spring Boot, Spring Web, Spring Data JPA, Thymeleaf, PostgreSQL,
Lombok, Spring Validation, Spring Security, Maven, JUnit

## Architecture
Frontend -> Controller -> Service -> Repository -> Database
